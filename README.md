# 🌍 Wandar-Lust

> Explore the world like never before. A modern, feature-rich web application built for travel enthusiasts to discover breathtaking destinations, plan trips seamlessly, and manage travel experiences with ease.

---

## ✨ Features

- **Destination Explorer:** Browse through a wide variety of stunning global locations with detailed information.
- **Advanced Filtering & Sorting:** Easily filter destinations by category and price range, or sort them by ratings and prices.
- **Interactive UI:** Smooth navigation, sleek card designs, and dynamic UI elements built with Tailwind CSS.
- **Dynamic Database Integration:** Fully connected backend API for fetching and managing destination data in real-time.
- **Responsive Design:** Optimized for mobile phones, tablets, and desktop screens.

---

## 🛠️ Tech Stack

**Frontend:**
- [Next.js](https://nextjs.org/) (React Framework)
- Tailwind CSS (Styling)
- TypeScript (Type Safety)
- Lucide React (Icons)

**Backend & Database:**
- Node.js & Express.js
- RESTful APIs
